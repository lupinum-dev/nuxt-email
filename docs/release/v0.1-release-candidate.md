## Frozen v0.1 contract

The authoring surface is the nineteen E-prefixed Nuxt auto-components:

- Document and layout: `EHtml`, `EHead`, `EBody`, `EContainer`, `ESection`, `ERow`, `EColumn`, `EHr`.
- Content: `EHeading`, `EText`, `ELink`, `EImg`, the Outlook-safe `EButton`, and the hidden `EPreview` preheader.
- Typography and code: `EFont`, `ECodeInline`, `ECodeBlock`.
- Authoring helpers: `EMarkdown` and `ETailwind` (render-time class inlining, including utilities emitted inside nested components).

Templates are ordinary Vue SFCs using Vue props, attributes, slots, `defineProps()`, `v-if`, and `v-for`. An optional `defineEmail({ subject })` server-side auto-import computes a subject line from a template's typed props.

The only application rendering API is the generated, server-only `renderEmail(name, props)`, returning exactly `{ html, text, subject? }`. `subject` is present only when the template declared one with `defineEmail`. Template names and props come from recursive `app/emails/` discovery. A public `nuxt-email/testing` subpath exposes `renderEmailComponent`, `normalizeEmailHtml`, and `RenderedEmail` for unit-testing emails without Nuxt. There is no provider adapter, send endpoint, alternate renderer, public registry protocol, or configuration surface in v0.1. Development preview consumes the same registry and renderer.

## Supported and unsupported surface

Supported behavior spans the nineteen primitives above plus complete-document rendering and plain-text conversion (nested lists, ordered-list starts, blockquotes, hard breaks, tables, preformatted text, links, Unicode, preview exclusion, and Outlook-safe button text), Prism code highlighting, Markdown conversion, `@font-face` loading, and Tailwind class inlining with head-injected non-inlinable rules.

This is not a claim of global or percentage compatibility. The six intentional divergences — `html-defaults`, four preview cases, and `row-columns` — and their Vue/email-safety reasons live in the generated [conformance report](../conformance/report.md). Closely translated MIT algorithms and release-notice requirements are recorded in [provenance](../conformance/provenance.md).

Not part of v0.1: provider adapters, send endpoints, raw-HTML primitives, JSX, React streaming, edge runtimes, configuration options, and a public registry protocol.
