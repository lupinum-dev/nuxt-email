`EEmail` is the root of every template. It renders the email document: `<html>`, `<head>`, the hidden preview text, and `<body>`.

## EEmail

```vue [app/emails/order-confirmed.vue]
<script setup lang="ts">
defineProps<{ orderNumber: string }>()
</script>

<template>
  <EEmail :subject="`Order ${orderNumber} confirmed`" lang="en" preview="Your order is on its way." class="bg-slate-100">
    <EText>Thank you for your order.</EText>
  </EEmail>
</template>
```

Each template renders exactly one `EEmail`, as its root. Nothing can surround it. A render fails when the template has no `EEmail`, has more than one, or wraps it in another element.

| Prop | Type | Default | Required |
| --- | --- | --- | --- |
| `subject` | `string` | — | Yes |
| `lang` | `string` | — | Yes |
| `preview` | `string` | — | No |
| `dir` | `'ltr' \| 'rtl' \| 'auto'` | `ltr` | No |
| `text` | `string` | — | No |

- `subject` becomes the `subject` of the render result. It is not written into the HTML.
- `lang` must be a non-empty string. `EEmail` sets `lang` and `dir` on `<html>`, `<body>`, and the inner body cell.
- `preview` is hidden inbox-preview text. It is truncated at 200 UTF-16 code units. Compatibility filler is added when the text is shorter. The preview is excluded from the plain text.
- `text` replaces the plain text that the renderer derives from the HTML. See [Plain text]($docs/guides/plain-text).

### Attributes go to the body

Other attributes on `EEmail` apply to `<body>`. `EEmail` renders `<body>` with a full-width presentation table. Author styles and classes apply to the inner cell. Background values and every class except padding-only ones such as `sm:p-8` also go to `<body>`, where margin and padding become zero.

`EEmail` accepts the [shared safe native attributes]($docs/components#rules-every-component-shares).

### Slots

| Slot | Content |
| --- | --- |
| `default` | The email body. |
| `head` | Extra `<head>` content, such as `<title>` or `EFont`. |

`<head>` always starts with the UTF-8 content-type and Apple message-reformatting meta tags. Content from the `head` slot follows them.

```vue
<EEmail subject="Order confirmed" lang="en">
  <template #head>
    <title>Order confirmed</title>
  </template>
  <EText>Your order is confirmed.</EText>
</EEmail>
```

`EEmail` does not generate a `<title>`. Add one in the `head` slot when you want it.

### Localization and right-to-left text

Keep localization in application code. Either create one literal template per locale, such as `welcome/en` and `welcome/ar`, or pass already-resolved strings through typed props. Do not call application-context internationalization composables inside an email template. Email templates render in an isolated server application.

```vue
<EEmail subject="تم تأكيد الطلب" lang="ar" dir="rtl">
  <EText>تم تأكيد طلبك.</EText>
</EEmail>
```

## EFont

`EFont` declares an `@font-face` and a document-wide default font. Place it in the `head` slot of `EEmail`.

| Prop | Type | Default | Required |
| --- | --- | --- | --- |
| `fontFamily` | `string` | — | Yes |
| `fallbackFontFamily` | `FontFallback \| readonly [FontFallback, ...FontFallback[]]` | — | Yes |
| `webFont` | `{ url: string, format: FontFormat }` | — | No |
| `fontStyle` | `'normal' \| 'italic' \| 'oblique'` | `normal` | No |
| `fontWeight` | `number \| 'normal' \| 'bold' \| 'bolder' \| 'lighter'` | `400` | No |

Supported fallbacks are `Arial`, `Helvetica`, `Verdana`, `Georgia`, `Times New Roman`, `serif`, `sans-serif`, `monospace`, `cursive`, and `fantasy`. Numeric weights must be from 1 through 1000. Web-font formats are `woff`, `woff2`, `truetype`, `opentype`, `embedded-opentype`, and `svg`.

`EFont` emits one `<style>` with the font-face rule and a global font stack. Outlook uses the first fallback through its specific `mso-font-alt` property. Invalid or empty values fail during rendering.

```vue
<template #head>
  <EFont
    font-family="Roboto"
    :fallback-font-family="['Verdana', 'sans-serif']"
    :web-font="{ url: 'https://fonts.example.com/roboto.woff2', format: 'woff2' }"
    :font-weight="700"
  />
</template>
```

::card{title="Client note" icon="lucide:mail"}
Only some clients honor web fonts. Choose a fallback stack that resembles the primary font and verify it in the clients you support.
::
